## ✍️ 如何添加新文章？

1. **放入 Markdown 文件**：在 `articles/` 目录下添加你的 `.md` 文章。
2. **配置侧边栏**：在 `_sidebar.md` 文件中添加文章链接：
   ```markdown
   * [文章标题](articles/文件名.md)
   ```
3. **推送更新**：推送至 GitHub 仓库，网站将自动即时更新。
