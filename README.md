## ✍️ 如何添加新文章？

你可以随时通过以下极简步骤添加新文章：

1. **新建 Markdown 文件**：在 `articles/` 目录下创建你的文章（例如 `articles/my-new-post.md`）。
2. **更新侧边栏**：在 `_sidebar.md` 文件中添加对应的链接：
   ```markdown
   * [我的新文章标题](articles/my-new-post.md)
   ```
3. **提交推送**：推送到 GitHub 后，网站将会自动实时更新！
