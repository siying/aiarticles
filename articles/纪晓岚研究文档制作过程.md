# 纪晓岚研究文档制作过程

## 一、目标

从明清笔记原始文献中，系统检索所有关于纪晓岚（纪昀）的记载，整理成一篇按时间线分析其形象演变的学术性文章。

## 二、数据来源

### 2.1 主要文本库：殆知阁古代文献（daizhige）

- **GitHub 仓库**：`garychowcmu/daizhigev20`（1642 stars，约2TB）
- **使用方式**：`git sparse-checkout`，只下载 `子藏/笔记` 目录
- **实际获取**：863部明清笔记全文 txt，共158MB
- **关键命令**：
  ```bash
  git clone --depth 1 --filter=blob:none --sparse https://github.com/garychowcmu/daizhigev20.git daizhige
  cd daizhige
  git sparse-checkout set "子藏/笔记"
  ```

### 2.2 正史来源

- 同一仓库的 `史藏/正史/清史稿.txt`
- 通过 sparse-checkout 额外下载

## 三、检索过程

### 3.1 关键词设计

纪晓岚有多个称呼，需全部覆盖：
- **纪昀**（正名）
- **纪晓岚**（字）
- **晓岚**（省称）
- **纪文达**（谥号）
- **纪公**（尊称）
- **春帆**（号）

### 3.2 初步检索

```bash
cd mingqing-biji
grep -rl "纪昀" *.txt | wc -l    # 219部
grep -rl "纪晓岚" *.txt | wc -l  # 15部
grep -rl "晓岚" *.txt | wc -l    # 19部
grep -rl "纪文达" *.txt | wc -l  # 22部
grep -rl "纪公" *.txt | wc -l    # 19部
```

### 3.3 段落级提取

用 Python 按段落分割，提取包含关键词的完整段落（避免只拿到半句话）：

```python
paragraphs = re.split(r'\n\s*\n', text)
for para in paragraphs:
    for name in names:
        if name in para:
            matched.append({'text': para, 'match': name, 'source': fname})
            break
```

### 3.4 结果统计

- **259部书**中找到相关内容
- **355条**原始匹配段落
- 过滤掉太短/纯目录条目后，**318条**有效记载

## 八、踩过的坑

1. **Wikisource 限流**：直接 HTTP 请求被 429/403，IP 被封
2. **ctext.org API 需认证**：无法免费批量获取
3. **GitHub 搜索不精准**：搜"明清笔记"返回大量无关仓库
4. **sparse checkout 耗时**：2TB 仓库即使 sparse 也要几分钟建索引
5. **"纪公"等词有歧义**：`经史百家杂钞`中的"莒纪公"是先秦人物，需人工过滤

## 九、核心发现

纪晓岚形象在130年间经历了五个阶段的演变：

| 时期 | 形象关键词 | 代表作者 |
|------|-----------|----------|
| 乾隆朝 | 淡泊谦逊的名士 | 纪昀本人 |
| 道光朝 | 博学异人，传说成型 | 梁章钜 |
| 咸同朝 | 学术权威 | 陆以湉 |
| 光绪朝 | 被引用的经典权威 | 俞樾 |
| 民国 | 政治符号（褒贬分裂） | 梁启超/易宗夔/刘声木 |
| 正史 | "读书多而不明理"的臣子 | 《清史稿》 |
