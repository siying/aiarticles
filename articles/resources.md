# AI 资源与精选工具集

整理 AI 开发者与研究者常用的高质量开源工具、框架与学习资源。

---

## 🛠️ 核心开发框架

| 框架名称 | 类别 | 简介 | 链接 |
| :--- | :--- | :--- | :--- |
| **LangChain** | 应用开发 | 最流行的 LLM 与 Agent 应用开发框架 | [官网](https://www.langchain.com/) |
| **LlamaIndex** | RAG / 数据 | 专为数据摄取、索引与检索增强生成的强大工具 | [官网](https://www.llamaindex.ai/) |
| **LiteLLM** | API 聚合 | 用统一的 OpenAI 格式调用 100+ 大模型 API | [GitHub](https://github.com/BerriAI/litellm) |
| **vLLM** | 推理加速 | 高吞吐、极速的 LLM 推理与服务引擎 (PagedAttention) | [GitHub](https://github.com/vllm-project/vllm) |
| **Ollama** | 本地运行 | 极简在本地电脑上一键运行开源大模型 | [官网](https://ollama.com/) |

---

## 📚 学习与文档推荐

- **Hugging Face**: 开源模型与数据集的最大社区与中心平台。
- **DeepLearning.AI**: Andrew Ng 创办的前沿 AI 与 LLM 实用课程。
- **Prompt Engineering Guide**: 全面系统的提示词工程学习指南。
