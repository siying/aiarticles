# 提示词工程 (Prompt Engineering) 实用指南

## 1. 什么是提示词工程？

提示词工程（Prompt Engineering）是指导与优化大语言模型（LLM）输入，以便从模型中获取更精准、高质量和稳定输出的艺术与工程方法。

---

## 2. 结构化提示词核心框架 (CRISPE 框架)

构建高质量 Prompt 时，建议采用结构化的模块定义：

| 模块 | 说明 | 示例 |
| :--- | :--- | :--- |
| **Capacity (角色与能力)** | 赋予模型明确的专家身份 | 你是一名拥有10年经验的资深 Python 架构师 |
| **Request (具体任务)** | 清晰定义要执行的任务 | 请审查以下代码片段并指出性能瓶颈与安全漏洞 |
| **Insight (背景与约束)** | 提供上下文信息与限制条件 | 运行环境为 Python 3.12，高并发场景，不可使用第三方库 |
| **Statement (指令步骤)** | 分步骤指导模型思考 | 1. 逐行分析复杂度；2. 提出优化建议；3. 给出重构后的代码 |
| **Personality / Style (输出风格)** | 指定语气与排版格式 | 请使用 Markdown 表格对比优化前后的时间复杂度 |
| **Experiment (少样本示例)** | 提供输入与理想输出的样本 | 输入: ... 输出: ... |

---

## 3. 常用进阶提示技巧

### 1. Few-Shot 提示（少样本提示）
通过给模型提供少量高质量的输入/输出范例，显著提升模型在特定格式或分类任务上的准确率。

```markdown
请将以下用户反馈归类为 [正面]、[负面] 或 [中性]：

反馈: “物流速度非常快，包装也很严实！”
分类: [正面]

反馈: “东西一般，感觉对不起这个价格。”
分类: [负面]

反馈: “商品已收到，正在测试中。”
分类: 
```

### 2. 思维链 (Chain of Thought, CoT)
引导模型在给出最终答案前，展示逐步推理的过程（"Let's think step by step"）。
- 对于数学运算、逻辑推理、复杂代码编写场景有巨大提升。

### 3. 结构化输出（JSON / Markdown）
在系统指令中明确约束模型只输出纯 JSON 或指定 Markdown 格式，便于程序下游解析：
```markdown
请提取文本中的实体信息，并严格以 JSON 格式输出，不要包含任何额外的解释说明或 Markdown 标记外壳。
```
